## 2. Environment-Dependent Capabilities (Honest Disclosure)

- **`yt-dlp` for YouTube / Twitch / Kick downloads**: Not bundled in the sandbox container. When `yt-dlp` is absent, YouTube links still fetch real title/author/thumbnail metadata via official oEmbed, and direct HTTPS `.mp4`/`.webm`/`.mov` URLs download natively. Installing `yt-dlp` on Windows/Linux/macOS immediately unlocks full URL downloading without code changes.
- **Cloud AI Providers**: Cloud keys (`GEMINI_API_KEY`, `GROQ_API_KEY`, `OPENROUTER_API_KEY`, etc.) are never stored in browser `localStorage` or typed into browser forms. Configure them strictly via server `.env` or environment secrets. Local providers (`Ollama`, `LM Studio`) work offline without cloud keys.
- **Channel Live Status & Campaign Payouts**: Channel checks verify real HTTPS reachability and explicitly mark live stream telemetry as `unconfirmed` unless connected to an authenticated platform API. Campaigns never fabricate view counts or earnings.
